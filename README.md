# Mohammed Abzan — Portfolio V4

A cinematic, story-driven portfolio using GSAP, Lenis, Three.js, scroll choreography, kinetic typography, interactive operations map, CV modal, dark/light mode and reduced-motion support.

## Run
Open `index.html` locally or deploy the folder to GitHub Pages.

## Content
Only supplied CV/profile information is used. MBA is listed as **Business Analytics — Currently Pursuing** without inventing an institution or completion date.

## Deployment
Upload the contents of this folder to your GitHub repository and enable GitHub Pages.
