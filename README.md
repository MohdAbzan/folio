# Mohammed Abzan — Portfolio V8 / Ultimate

Premium monochrome, story-driven portfolio using the original professional photo and actual CV-supported information.

### Design direction
- Cinematic hero and editorial typography
- Guided chapter navigation
- Career timeline as a scroll story
- Interactive operations/work system
- MBA Business Analytics transition visual
- Toolkit and education interface
- Subtle cursor, hover and parallax interactions
- Responsive mobile choreography
- Reduced-motion support
- No invented achievements or statistics
- No “Open to Work”
