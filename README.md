# Mohammed Abzan — Final Portfolio

Premium single-page portfolio website for Mohammed Abzan.

## Highlights
- One original personalized portrait asset reused throughout the experience
- Full-bleed hero photography with a subtle blurred depth layer
- Hero typography protected by a dark editorial gradient so the name remains readable
- Work Story section with a large portrait and scroll-linked image movement
- GSAP + ScrollTrigger entrance, parallax, clip reveals and data visual animations
- Animated operations system and interactive hover states
- Responsive mobile navigation and layout
- Reduced-motion accessibility support
- Direct CV link using the supplied resume

## Run
Open `index.html` in a browser, or deploy the folder to GitHub Pages.
