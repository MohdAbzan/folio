# ABZAN — Experience 06

A cinematic, recruiter-friendly portfolio for Mohammed Abzan.

## Includes
- User-supplied transparent portrait cutout
- Scroll-driven storytelling with GSAP + ScrollTrigger
- Three.js ambient particle field
- Kinetic typography and staged reveals
- Interactive portrait tilt and custom cursor on desktop
- Operations Core visual system
- MBA Business Analytics story
- CV preview modal
- Responsive mobile layout
- Reduced-motion fallback
- No "Open to Work" label
- No invented achievements or percentages

## Run
Open `index.html` in a modern browser. Internet access is required for the CDN libraries and fonts.
