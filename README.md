# Mohammed Abzan — Portfolio

A premium, recruiter-first one-page portfolio built around Mohammed Abzan's real CV information and one original professional portrait.

## Includes
- Full original portrait shown without cropping in the hero
- Black / white editorial visual system with subtle gold detail
- Scroll-linked motion, reveals, progress indicator and animated data visuals
- Experience, working approach, tools, education, languages and contact
- Direct CV access from the supplied resume
- Responsive mobile navigation
- Reduced-motion support

## Run
Open `index.html` in a browser, or deploy the folder to GitHub Pages / Netlify / Vercel.
